# 1. Record architecture decisions

## Context

Several people and coding agents work on this repo in short sessions. Decisions made in one session need to be visible in the next.

## Decision

Record real architectural decisions as short ADRs in `docs/decisions/`, numbered sequentially, each with Context, Decision and Consequences, about 20 lines max.

## Consequences

- New sessions read `docs/decisions/` to learn why things are the way they are.
- Trivial choices don't get an ADR.
